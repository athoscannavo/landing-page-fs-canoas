3. Athos Cannavo:
Prompt para ajudar com os merges e commits entre as branchs.

Contexto:
estou no comando desse repositorio git e estou encarregado das branchs dev, main e release. É regra de negócio que devemos colocar as primeiras versões funcionais de nosso código na branch dev, solucionar problemas de compatibilidade antes de enviar para a branch main e postar apenas as versões funcionais que serão acessadas pelos clientes na branch release. 

Objetivo: Ajudar a dar stage, fazer pulls, commits e  pushs para controlar o repositório de maneira eficaz através do VS code, Fazer trocas de branch e  manter-las atualizadas de maneira correta.

Como me ajudar: quando eu pedir para realizar uma tarefa, me dê um passo a passo contextualizado e sequencial sobre como posso realizar essa tarefa de maneira segura e sem danificar o projeto.
